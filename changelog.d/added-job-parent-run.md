- Spend from a Deadline Cloud job, started by a **Deadline Cloud Published Workflow** node or a
  **Deadline Cloud Multi Task Group**, now counts toward the workflow run that started it, so that
  run's total in Griptape Cloud includes it. A workflow published before this version still runs, but
  its spend stays separate until it is published again.
